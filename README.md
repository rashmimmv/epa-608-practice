# EPA 608 Practice Exam

Free 20-question practice quiz for the EPA Section 608 refrigerant certification exam.

**Live site:** https://epa608practice.mangalmurtivibes.com

## About

This site helps HVAC technicians prepare for the EPA 608 certification exam required under Section 608 of the Clean Air Act. The quiz covers all four certification types:

- **Type I** — Small appliances (5 lbs or less of refrigerant)
- **Type II** — High-pressure systems (R-22, R-410A, etc.)
- **Type III** — Low-pressure systems (R-11, R-123, etc.)
- **Universal** — All types

Topics include refrigerant classification, recovery, recycling, reclaiming, leak repair requirements, venting prohibitions, and technician certification rules.
